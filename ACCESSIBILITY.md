## Overview
This file will document the auditing process for accessbility. 
It will document the results of the PageSpeed Insights audit,
as well as the manual testing done to ensure keyboard
navigation and accessibility is properly implemented.

## Initial Results
The audit of my portfolio page produced very strong results.
In fact, the site scored 100 on accessibility for both mobile
and desktop devices right out of the gate.

Since the lab requirements place a focus on keyboard navigation,
I decided to perform a manual audit to ensure it is working properly
and efficiently.

## Manual Keyboard Audit
The manual audit of keyboard accessibility found that the website's existing
keyboard navigation features work as inteded. Things like skip navigation,
focus indicators, logical tab order, and accessing each section of the website
were tested. No significant accessibility issues were found during this test,
so no code changes were necessary. 

## Final Results
The PageSpeed Insights and manual audit of this webpage have ensured that all
accessibility features expected of a website such as this are present and 
properly working. These results demonstrate that this website meets the 
accessibility goals discussed for this lab.
