### Movie Tycoon Project
This project is a very early version of what will eventually be an
interactive progress through several stages of building their own movie. The end
result of the process is a critic score and finnancial report. It is
currently very rudimentary, but there is much planned for its
future.

One significant challenge I have faced with this project is accurately calculating the critic score for each movie created. With the creation process taking several stages, each with its own choices, there is a lot to factor in. It is difficult to fine-tune the calculation so that it is somewhat representative of real-world scores, but also allows some freedom and experimentation. 

Built with: Godot

Things I learned:
Managing the different interacting elements when creating even a
simple game is a complex process. Even the simplest of features
requires strict planning.
